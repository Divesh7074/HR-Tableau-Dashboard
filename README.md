# HR Analytics Dashboard | Data Analytics Project



**Project Overview**
The HR Analytics Dashboard is designed to analyze employee data and provide meaningful insights into workforce performance, employee demographics, attrition, and departmental distribution.

This project helps HR professionals and management make data-driven decisions, monitor employee trends, and improve workforce planning.

**Project Objectives**
- Analyze total employee count.
- Understand employee attrition and turnover rate.
- Analyze gender distribution.
- Track employee distribution across departments.
- Analyze employee age groups.
- Identify job satisfaction levels.
- Understand employee performance and workforce trends.

**Tools & Technologies**
- **Tableau** – Data Visualization and Dashboard Development
- **Microsoft Excel** – Data Cleaning and Data Preparation
- **Data Analytics** – Exploratory Data Analysis (EDA)

**Key Dashboard Insights**
- Total Employees
- Employee Attrition Rate
- Active Employees
- Gender Distribution
- Department-wise Employee Count
- Age Group Analysis
- Job Satisfaction Analysis
- Education and Job Role Analysis

**Business Value**
This dashboard helps HR teams:
- Identify employee attrition patterns.
- Understand workforce demographics.
- Monitor department-wise employee distribution.
- Improve employee retention strategies.
- Make informed HR decisions using data.
